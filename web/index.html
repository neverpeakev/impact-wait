Add it to your AI app

1. InstallA plugin for Open WebUI, a ready fork of LibreChat or the Vercel AI Chatbot, or one tag for any web app.
2. Pick a site keyAny name you like, e.g. riverside-library. It registers on first use and joins the leaderboard.
3. That's itViews only count after 1 second on screen. No cookies, no user tracking, no ad keys on your server.
  1. Download the filter (one Python file).
  2. Admin Panel > Functions > + > Import, and pick the file.
  3. Open its Valves and set site to your key.
  4. Turn it on and make it Global (three-dot menu).

Runs sandboxed in the user's browser. Nothing is sent from your server. Users can switch it off in Settings > Functions. Tested on Open WebUI 0.11.

# fresh install: our LibreChat fork
git clone https://github.com/neverpeakev/impact-librechat.git
cd impact-librechat && cp .env.example .env
echo "IMPACT_WAIT_SITE=your-site" >> .env
docker compose up -d

Already running LibreChat? Apply the patch (git apply librechat.patch) and rebuild. Users get a "Show Sponsored Line While Waiting" switch in Settings > Chat. IMPACT_WAIT=off turns it off for everyone.
